# TTS (Text-to-Speech) System Documentation

## Overview

The TTS system converts timestamped SRT script files into synchronized speech audio using the ElevenLabs Text-to-Speech API. It's a critical component of the STEMViz pipeline that generates natural-sounding narration timed to match the visual animations.

## Architecture

### Core Component: `AudioSynthesizer`

Located in `generation/audio_synthesizer.py`, the `AudioSynthesizer` class handles:

- SRT file parsing and timestamp extraction
- Individual audio segment generation via ElevenLabs API
- Audio concatenation with precise timing synchronization
- Duration validation and silence padding
- Error handling with retry logic

### Data Models

```python
class AudioSegment(BaseModel):
    text: str                    # Subtitle text content
    start_time: float           # Start time in seconds
    end_time: float             # End time in seconds
    audio_path: Optional[str]   # Path to generated audio file
    duration: Optional[float]   # Actual audio duration
    file_size: Optional[float]  # File size in MB

class AudioResult(BaseModel):
    success: bool
    audio_path: Optional[str]           # Final concatenated audio file
    audio_segments: List[AudioSegment]  # All individual segments
    total_duration: Optional[float]     # Total audio duration
    file_size_mb: Optional[float]       # Final file size
    error_message: Optional[str]        # Error details if failed
    generation_time: Optional[float]    # Processing time in seconds
    voice_settings: Optional[Dict]      # Voice configuration used
    model_used: str                     # TTS model identifier
```

## Inputs

### Primary Input: SRT Script File
- **Format**: Standard SRT subtitle format
- **Location**: Generated by `ScriptGenerator` in the pipeline
- **Structure**: Sequential subtitles with timestamps and text
- **Example**:
  ```
  1
  00:00:01,800 --> 00:00:05,200
  Welcome to our exploration of bubble sort algorithm.

  2
  00:00:05,200 --> 00:00:08,500
  Let's start with an unsorted array of numbers.
  ```

### Optional Input: Target Duration
- **Type**: `float` (seconds)
- **Purpose**: Match audio duration to video length
- **Behavior**: Adds silence padding if audio is shorter than target

## Configuration

### TTS Settings (from `config.py`)

```python
tts_voice_id: str = "JBFqnCBsd6RMkjVDRZzb"        # ElevenLabs voice ID
tts_model_id: str = "eleven_multilingual_v2"       # TTS model
tts_stability: float = 0.75                       # Voice stability (0-1)
tts_similarity_boost: float = 0.75                # Similarity boost (0-1)
tts_style: float = 0.0                            # Style exaggeration (0-1)
tts_use_speaker_boost: bool = True                # Enhance voice clarity
tts_max_retries: int = 3                          # API call retry attempts
tts_timeout: int = 120                            # Request timeout (seconds)
```

### Voice Settings Explained
- **Stability**: Controls consistency vs. expressiveness (higher = more consistent)
- **Similarity Boost**: Enhances voice similarity to original (higher = more similar)
- **Style**: Controls expressiveness and emotion (higher = more expressive)
- **Speaker Boost**: Improves voice clarity and quality

## Outputs

### Primary Output: Synchronized Audio File
- **Format**: MP3 (44.1kHz, 128kbps)
- **Location**: `{output_dir}/{script_stem}_audio_{timestamp}.mp3`
- **Timing**: Precisely synchronized with SRT timestamps
- **Quality**: 192kbps bitrate for final concatenated audio

### Secondary Outputs
- **Temporary Segments**: Individual audio files in `{output_dir}/segments/`
- **Metadata**: `AudioResult` object with processing details
- **Statistics**: Performance metrics and configuration info

## Process Flow

### 1. SRT Parsing
- Reads and validates SRT file format
- Extracts sequence numbers, timestamps, and text
- Normalizes malformed timestamps
- Converts timestamps to seconds for processing

### 2. Audio Generation (Per Segment)
For each subtitle:
- Calls ElevenLabs TTS API with text and voice settings
- Handles API errors with exponential backoff retry
- Saves individual audio segment as temporary MP3 file
- Measures actual audio duration

### 3. Audio Concatenation
- Sorts segments by start time
- Adds silence gaps to match SRT timing
- Concatenates segments using pydub
- Exports final synchronized audio file

### 4. Duration Validation
- Measures final audio duration
- Compares with target duration (if provided)
- Adds silence padding if needed to match target

## Dependencies

### External APIs
- **ElevenLabs TTS API**: Primary text-to-speech service
  - Requires API key (`ELEVENLABS_API_KEY` environment variable)
  - Supports multiple voices and models
  - Rate limiting and quota management

### Python Libraries
- `elevenlabs>=1.0.0`: TTS API client
- `pydub>=0.25.1`: Audio processing and manipulation
- `pydantic>=2.0.0`: Data validation and models
- `pathlib`: File system operations

### System Dependencies
- **FFmpeg**: Required by pydub for audio processing
- **File System**: Temporary storage for audio segments

## Performance Characteristics

### Processing Time
- Typically 2-5 seconds per subtitle segment
- Depends on text length and API response time
- Parallel processing not implemented (sequential)

### File Sizes
- Individual segments: ~50-200 KB each
- Final audio: ~1-5 MB for typical educational content
- Temporary files cleaned up after successful completion

### API Usage
- One API call per subtitle segment
- Token usage varies by text length
- Subject to ElevenLabs rate limits and quotas

## Troubleshooting

### Common Issues
1. **API Key Errors**: Verify `ELEVENLABS_API_KEY` environment variable
2. **Timing Mismatches**: Check SRT format and timestamp parsing
3. **Audio Quality**: Adjust voice settings (stability, similarity_boost)
4. **Rate Limiting**: Increase timeout or reduce concurrent requests
5. **File Permissions**: Ensure write access to output directory
